# WeChat Channels (视频号) Hard Specifications

| Field | Limit / Rule |
| --- | --- |
| Supported Modes | `video` primary (Creator Studio also supports image posts up to 9 images) |
| Short Title Length | Max **16** characters |
| Description Length | Max **1000** characters |
| Topics | Native `#topic` supported |
| Video | 1 video (`mp4`, `avi`, `mkv`, `mov`, `flv`, `rmvb`, `wmv`, `webm`), max **1 GB**, max **3600s** |
| Cover Image | `jpg`, `jpeg`, `png`, `bmp`, max **20 MB** |
| Publishing Path | Browser Creator Studio (`channels.weixin.qq.com`) with draft staging + human confirmation |
