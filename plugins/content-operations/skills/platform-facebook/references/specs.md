# Facebook Page Hard Specifications

| Field | Limit / Rule |
| --- | --- |
| Supported Modes | `text`, `image_text`, `video` (Feed, Photos, Videos, Reels, Stories) |
| Body Length | Max **63206** characters |
| Images | 1–**10** images (`jpg`, `jpeg`, `png`, `gif`, `bmp`, `tiff`), max **10 MB** each |
| Video | 1 video (`mp4`, `mov`, `avi`), max **1 GB**, max **3600s** |
| Topics | No native API topic field |
| Options | `link` (HTTPS), `content_category`, `content_tags`, `custom_labels`, `embeddable`, `video_state`, `feed_targeting` |
| Account Requirement | Requires a Facebook **Page** (not a personal profile) |
| Live URL Patterns | `https://www.facebook.com/<postId>` or `/reel/<reelId>` |
