# Example 4 — Live Photo Motion Cards

Finished visual reference for three Live Photo motion-card layouts (`1080×1440`):
1. `live-single-01` — Single-video motion card (`5.0s` Xiaohongshu) with one restrained title group placed strictly inside the quiet top band.
2. `live-triple-02` — Triple-row parallel comparison (`5.0s` Xiaohongshu) placing 3 side-by-side results in one card.
3. `live-quad-03` — Material-first four-grid puzzle (`3.0s` WeChat Official Account) with zero overlay text.
