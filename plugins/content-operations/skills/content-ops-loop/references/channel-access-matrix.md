# 14-Platform Legitimate Channel Access Matrix

This plugin operates strictly through **three legitimate, platform-official channels**—never extract browser session cookies, call reverse-engineered private endpoints, or bypass login/CAPTCHA challenges:

1. **Connected Ducoro Core Connectors (Check First When Available)** — before asking the user to configure developer apps or fall back to manual browser steps, check whether Ducoro already has an active Connector for the target platform (`ducoro-cli mcp catalog list --json`, `ducoro-cli mcp catalog status <slug> --json`, `ducoro-cli mcp catalog tools <slug> --json`). When a connected Connector exposes the required publish, comment, or analytics tool, invoke the mounted Connector tool (or `ducoro-cli mcp catalog call <slug> <tool> --args-file <path|-> --json`) while still enforcing Gate 2 approval and `engagement_guard.py`.
2. **Official Browser Creator Studio (Default Zero-Config Fallback, All 14 Platforms)** — works across **all 14 platforms** (including CN platforms not covered by Connectors, and web-only Studio features like YouTube CTR or personal LinkedIn impressions) with zero developer-app setup and direct local file upload from `drafts/<draft-id>/assets/`. Always pause for human sign-in/CAPTCHA and pause before final publish at Gate 2.
3. **Official Platform OpenAPI (`scripts/client.py`, Optional User-Owned Credentials)** — works on **12 platforms** when the user holds official developer tokens in environment variables or needs deep endpoints not exposed by a Connector (e.g., YouTube Analytics v2 AVD/AVP reports, WeChat Official multi-day stats, or standalone non-Ducoro hosts).

## Channel Selection Rule

1. **Ducoro Core Connectors first**: When running inside Ducoro, check `ducoro-cli mcp catalog list --json`, `ducoro-cli mcp catalog status <slug> --json`, and `ducoro-cli mcp catalog tools <slug> --json`. If the platform Connector is active and exposes the needed publish/comment/analytics tool, invoke it first (still enforcing Gate 2 approval and `engagement_guard.py`).
2. **Official Browser Creator Studio second (default zero-config, all 14 platforms)**: When no matching Connector tool exists—including CN platforms, accounts marked `manual_browser` in `accounts.json`, or Studio-only features/metrics—use the Official Browser Creator Studio path immediately with direct local uploads from `drafts/<draft-id>/assets/` (pause for human login/CAPTCHA and Gate 2).
3. **Official OpenAPI `scripts/client.py` third (advanced optional, 12 platforms)**: When the user has explicitly configured official developer API env vars (or needs deep API endpoints such as YouTube Analytics v2 reports), run `scripts/client.py` (always preview with `--dry-run` during setup, and use `ducoro-cli media upload <path> --json` for Meta/Pinterest 5-hour URL relay).
4. Never attempt to bridge missing API tokens by scraping cookies from the browser.
